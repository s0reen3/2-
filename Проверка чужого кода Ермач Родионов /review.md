Плюсы кода (+)

        Использование цепочки (if-elif-else) логично для ветвления по операциям и легко считывается новичком.
  
        Присутствует проверка (if b != 0:), что предотвращает падение программы с ошибкой (ZeroDivisionError).

        Корректное приведение типов: Ввод преобразуется в (float), что позволяет калькулятору правильно работать с дробными числами, а не только с целыми.

  Минусы и критические ошибки (-)

        В блоке (elif d == '*':) выводится текст (print('Выбрано вычитание')). Это запутает пользователя.
  
        Запросы чисел a и b и вывод сообщений повторяются в каждом блоке. Это усложняет поддержку кода. Если потребуется изменить текст запроса, придется править его в 5 местах.
  
        Если пользователь вместо числа случайно введет букву, программа упадет с ошибкой ValueError.
  
        Извлечение корня работает только для квадратного корня (степень 0.5), а текст запроса Введите корень: может запутать (лучше 'Введите число:'). Также нет проверки на отрицательные числа (вызовет ошибку или комплексное число).
  
        Программа завершает работу сразу после одного вычисления. Пользователю приходится запускать её заново.
  
        Отсутствие ветки (else) в конце: Если ввести неверный символ (например, 'abc'), программа просто завершится без какого-либо сообщения об ошибке.
